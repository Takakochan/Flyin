問題点： A* と CBS はパスを「タイムステップのインデックスつき列」として扱う。Timeline に変えると、衝突検出・制約チェック・コスト計算もすべて書き直しになる。これは tuple リファクタリングと同じ規模の変更。

おすすめの使い方： Timeline は 出力レイヤー専用 にする。

A* → list[str]  ←  CBS が使う（変えない）
                ↓  変換関数 1本
            Timeline  ← draw_map と _print_capacity_info が使う

変換関数はシンプル：

def to_timeline(paths: Paths) -> Timeline:
    max_t = max(len(p) for p in paths.values())
    tl = Timeline()
    for t in range(max_t):
        events = []
        for drone_id, path in paths.items():
            zone = path[t] if t < len(path) else path[-1]
            events.append(MoveEvent(drone_id, zone))
        tl.add_turn(events)
    return tl

- A* / CBS の中身は一切触らない
- draw_map の - 記法バグはここで吸収できる
